# Booking System

Simple room booking frontend (Vue 3 + Vite).

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Backend

API is proxied via Vite to: `https://fast-api-9luc.onrender.com`

Frontend uses: `VITE_API_BASE_URL=/api`

Rooms list endpoint: `GET /api/rooms`
